# Análisis del Escenario Técnico - Sistema Help Desk Data Center

## 5. Creación del Diagrama de Casos de Uso

Como parte del diseño del sistema Help Desk orientado a la gestión de incidentes en un Data Center, se elaboró un diagrama de casos de uso mediante la herramienta Draw.io. Este diagrama permite representar de forma visual la interacción entre los actores principales del sistema y las funcionalidades disponibles para cada uno.

El sistema fue denominado *Sistema Help Desk - Data Center* y dentro de su estructura se identificaron tres actores principales:

### Actores del Sistema
- *Usuario Final*: Persona encargada de reportar incidencias y consultar el estado de sus solicitudes.
- *Técnico de Soporte*: Responsable de atender los tickets asignados, actualizar avances y registrar soluciones.
- *Administrador del Sistema*: Encargado de supervisar la operación general, asignar recursos y generar reportes administrativos.

### Casos de Uso Implementados

#### Funciones del Usuario Final
- Crear ticket
- Consultar estado del ticket

#### Funciones del Técnico de Soporte
- Actualizar estado del ticket
- Registrar solución

#### Funciones del Administrador del Sistema
- Asignar técnico
- Gestionar técnicos
- Generar reportes
- Cerrar ticket

Este diagrama facilita la comprensión de los requerimientos funcionales del sistema, permite delimitar responsabilidades por actor y sirve como base para las siguientes fases del diseño, como el diagrama de clases UML y la arquitectura general del sistema.
